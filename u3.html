Linear Regression: Complete Master Reference

Intuitive Theory, Mathematical Steps, Visual Landscapes & Code Implementation

1. Types of Linear Regression

Simple Idea: Linear regression predicts an outcome variable (\(y\)) by fitting a straight line (or plane) through your data points.

1. Simple Linear Regression

Uses one single input feature (\(x\)) to predict the target variable (\(y\)).

Example: Predicting salary based only on years of experience.

$$\hat{y} = \beta_0 + \beta_1 x$$

2. Multiple Linear Regression

Uses two or more input features (\(x_1, x_2, \dots, x_p\)) to predict the target (\(y\)).

Example: Predicting house price based on area, number of bedrooms, and location score.

$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p$$

2. Why Slope (\(\beta_1\)) and Intercept (\(\beta_0\)) Matter

$$\hat{y} = \underbrace{\beta_0}_{\text{Starting Value}} + \underbrace{\beta_1}_{\text{Rate of Change}} \cdot x$$

Y-Intercept (\(\beta_0\))

What it is: The baseline value of \(\hat{y}\) when the input \(x = 0\).

Real-World Meaning: If experience \(x = 0\), \(\beta_0\) represents the starting base salary for a fresh graduate.

Slope Coefficient (\(\beta_1\))

What it is: How much \(\hat{y}\) changes for every 1-unit increase in \(x\).

Real-World Meaning: If \(\beta_1 = 5000\), it means every additional year of experience adds $5,000 to the salary.

3. OLS Method — Detailed Theory With Equations

OLS (Ordinary Least Squares) is the mathematical method used in linear regression to find the line that best represents the relationship between \(X\) and \(Y\).

1. Regression equation

For simple linear regression:

$$\hat{Y} = b_0 + b_1 X$$

Where:

  • \(\hat{Y}\) = predicted value of \(Y\)
  • \(b_0\) = intercept
  • \(b_1\) = slope
  • \(X\) = input/independent variable

Example:

$$\hat{Y} = 2 + 3X$$

If \(X = 4\):

$$\hat{Y} = 2 + 3(4) = 14$$

So predicted \(Y = 14\).

2. Actual value vs predicted value

Suppose actual value is \(Y = 16\) and predicted value is \(\hat{Y} = 14\).

Then the residual/error is:

$$e = Y - \hat{Y}$$
$$e = 16 - 14 = 2$$

So: Residual = Actual − Predicted

3. Why do we square the error?

Some errors can be positive and some negative. For example: \(e_1 = 2\) and \(e_2 = -2\).

If we simply add them: \(2 + (-2) = 0\). It looks like there is no error, which is wrong.

So OLS squares the errors: \(2^2 + (-2)^2 = 4 + 4 = 8\).

Therefore, OLS uses:

$$SSE = \sum (Y - \hat{Y})^2$$

where \(SSE\) = Sum of Squared Errors.

4. Main objective of OLS

The main objective is:

$$\mathbf{\text{Minimize } \sum (Y - \hat{Y})^2}$$

In simple words: OLS searches for the line where the total squared error is minimum. That's why it is called Least Squares.

5. How do we find the slope (\(b_1\))?

The OLS slope formula is:

$$\mathbf{b_1 = \frac{\sum (X - \bar{X})(Y - \bar{Y})}{\sum (X - \bar{X})^2}}$$

Where: \(X\) = each \(X\) value, \(Y\) = each \(Y\) value, \(\bar{X}\) = mean of \(X\), \(\bar{Y}\) = mean of \(Y\).

Meaning of the formula:

The numerator \(\sum (X - \bar{X})(Y - \bar{Y})\) tells us how \(X\) and \(Y\) move together.

The denominator \(\sum (X - \bar{X})^2\) measures the variation in \(X\).

$$\text{Slope} = \frac{\text{how } X \text{ and } Y \text{ move together}}{\text{variation in } X}$$

6. How do we find the intercept (\(b_0\))?

After finding the slope, use:

$$\mathbf{b_0 = \bar{Y} - b_1 \bar{X}}$$

So the order is:

$$\text{Find } \bar{X} \rightarrow \text{Find } \bar{Y} \rightarrow \text{Find } b_1 \text{ (slope)} \rightarrow \text{Find } b_0 \text{ (intercept)} \rightarrow \text{Create regression equation}$$

7. Complete example

Take dataset:

X 1 2 3 4 5
Y 2 4 5 4 5

Step 1: Find means

$$\bar{X} = \frac{1+2+3+4+5}{5} = 3, \quad \bar{Y} = \frac{2+4+5+4+5}{5} = 4$$

Step 2: Calculate slope

For this data, \(\sum (X - \bar{X})(Y - \bar{Y}) = 6\) and \(\sum (X - \bar{X})^2 = 10\).

$$b_1 = \frac{6}{10} = 0.6$$

Step 3: Calculate intercept

$$b_0 = 4 - (0.6)(3) = 2.2$$

Step 4: Regression equation

$$\mathbf{\hat{Y} = 2.2 + 0.6X}$$

8. Predict a value

For \(X = 6\):

$$\hat{Y} = 2.2 + 0.6(6) = \mathbf{5.8}$$

9. Calculate residual

If the actual \(Y\) for \(X = 6\) is \(7\):

$$e = Y - \hat{Y} = 7 - 5.8 = 1.2$$

Squared error:

$$e^2 = (1.2)^2 = 1.44$$

OLS does this for every observation and adds all the squared errors: \(SSE = e_1^2 + e_2^2 + e_3^2 + \dots + e_n^2\). The best regression line is the one that gives the minimum \(SSE\).

10. The whole OLS concept in one flow

$$\mathbf{\text{Data} \rightarrow \bar{X}, \bar{Y} \rightarrow b_1 \rightarrow b_0 \rightarrow \hat{Y} \rightarrow e = Y - \hat{Y} \rightarrow SSE = \sum e^2}$$

Most important equations to remember

  • Regression equation: \(\hat{Y} = b_0 + b_1 X\)
  • Slope: \(b_1 = \frac{\sum(X - \bar{X})(Y - \bar{Y})}{\sum(X - \bar{X})^2}\)
  • Intercept: \(b_0 = \bar{Y} - b_1 \bar{X}\)
  • Residual: \(e = Y - \hat{Y}\)
  • Sum of Squared Errors: \(SSE = \sum(Y - \hat{Y})^2\)
  • OLS objective: \(\min SSE\)

In one sentence: OLS finds \(b_0\) and \(b_1\) such that the sum of squared differences between actual \(Y\) and predicted \(Y\) is as small as possible.

4. Optimization via Gradient Descent

Simple Idea: Instead of calculating parameters instantly using calculus, start with initial parameter values, evaluate your error, and take small steps downhill until you reach the lowest error.

1. Initialize Parameters

Start with initial values for slope (\(m\)) and intercept (\(b\)).

2. Calculate the Cost Function

Measure the error using the Mean Squared Error (MSE):

$$J(m,b) = \frac{1}{n} \sum_{i=1}^{n} (y_i - (m x_i + b))^2$$

3. Compute the Gradient

Calculate how much the cost function changes with respect to \(m\) and \(b\):

For slope \(m\):

$$\frac{\partial J}{\partial m} = -\frac{2}{n} \sum_{i=1}^{n} x_i (y_i - (m x_i + b))$$

For intercept \(b\):

$$\frac{\partial J}{\partial b} = -\frac{2}{n} \sum_{i=1}^{n} (y_i - (m x_i + b))$$

4. Update Parameters

Change \(m\) and \(b\) to reduce the error:

For slope \(m\):

$$m = m - \alpha \cdot \frac{\partial J}{\partial m}$$

For intercept \(b\):

$$b = b - \alpha \cdot \frac{\partial J}{\partial b}$$

Here \(\alpha\) is the learning rate that controls the size of each update.

5. Repeat

Keep repeating steps 2–4 until the error stops decreasing significantly.

5. Loss Evaluation Metrics: MAE, MSE, and RMSE

Mean Absolute Error (MAE): Average absolute difference.

$$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

Mean Squared Error (MSE): Average squared difference.

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

Root Mean Squared Error (RMSE): Square root of MSE.

$$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$
Metric Advantages Disadvantages
MAE Easy to interpret; robust against severe outliers. Gradient is non-differentiable at 0 error; doesn't heavily penalize large errors.
MSE Fully differentiable; heavily penalizes large errors. Units are squared (\(y^2\)), making direct interpretation difficult.
RMSE Expressed in original target units (\(y\)); differentiable. Sensitive to severe outliers compared to MAE.

6. Goodness of Fit: \(R^2\) and Adjusted \(R^2\)

\(R^2\) Score (Coefficient of Determination)

$$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

Meaning: Proportion of variance in target variable explained by the model.

Adjusted \(R^2\) Score

$$\text{Adjusted } R^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$

Meaning: Penalizes model complexity (\(p\)). Only increases if new features genuinely improve model performance.

7. Key Assumptions of Linear Regression

  1. Linearity: The target \(y\) has a linear relationship with predictor features.
  2. Homoscedasticity: Variance of errors remains constant across all values of features.
  3. Independence: Observations and residuals are independent of each other (no autocorrelation).
  4. Normality of Residuals: Error terms follow a normal distribution centered at 0.
  5. No Multicollinearity: Features are not strongly correlated with each other.

8. Complete Python Implementation (OLS & Gradient Descent)

Below is the complete implementation of Linear Regression including both Ordinary Least Squares (OLS) closed-form calculation and iterative Gradient Descent:

import numpy as np

# Sample Data
x = np.array([1, 2, 3, 4, 5], dtype=float)
y = np.array([2, 4, 5, 4, 5], dtype=float)
n = len(x)

# ==========================================
# 1. ORDINARY LEAST SQUARES (OLS) METHOD
# ==========================================
# Formulas:
# m = sum((x_i - mean_x) * (y_i - mean_y)) / sum((x_i - mean_x)^2)
# b = mean_y - m * mean_x

x_mean = np.mean(x)
y_mean = np.mean(y)

b1 = np.sum((x - x_mean) * (y - y_mean)) / np.sum((x - x_mean) ** 2)
b0 = y_mean - b1 * x_mean

y_pred_ols = b0 + b1 * x

print("--- OLS Method Results ---")
print("Slope (b1):", b1)
print("Intercept (b0):", b0)
print("Predicted values:", y_pred_ols)

# ==========================================
# 2. GRADIENT DESCENT METHOD
# ==========================================
# Step 1: Initialize Parameters
m = 0.0
b = 0.0

# Hyperparameters
learning_rate = 0.01
epochs = 1000

# Optimization Loop
for _ in range(epochs):
    # Step 2 & 3: Compute Predictions & Gradients
    # dJ/dm = -2/n * sum(x * (y - (m*x + b)))
    # dJ/db = -2/n * sum(y - (m*x + b))
    y_pred = m * x + b
    error = y - y_pred
    
    dj_dm = (-2 / n) * np.sum(x * error)
    dj_db = (-2 / n) * np.sum(error)
    
    # Step 4: Update Parameters
    m = m - (learning_rate * dj_dm)
    b = b - (learning_rate * dj_db)

y_pred_gd = m * x + b

print("\n--- Gradient Descent Results ---")
print("Slope (m):", m)
print("Intercept (b):", b)
print("Predicted values:", y_pred_gd)
